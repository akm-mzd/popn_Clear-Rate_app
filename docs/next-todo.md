# 次にやること（ユーザーからの依頼のメモ）

まだ作っていない。始めるときは、このメモと `docs/ran-knock.tsv` を読み、細かいところをユーザーに確かめてから作る。

## 1. 次にプレーする曲のメモ（「次にやる」）

- 曲を「次にやる」に入れて、一覧（リスト表示）で見られるようにする。
- 入れ方は2つ。
  - 曲のメモのところ（曲の詳細ページのメモ、リストの 📝）から入れる。
  - 「次にやる」のページで曲名などを入れて検索し、出てきた曲を入れる。
- 公式データの取り込みで、その曲に変化（メダル・スコア・BAD のどれか）があったら、自動で一覧から消す。
- 変化がなくてもプレーした可能性があるので、手でも消せるようにする。

## 2. ランダムノック表・S乱ノック表

- 乱ノック表と S乱ノック表を、ノック難易度の順に並べて出す。
- ノック難易度はユーザーが用意する。
  - 乱ノック：`docs/ran-knock.tsv` に保存済み（166譜面）。
  - S乱ノック：まだ。あとでもらう。
- 「それぞれのノックのページに移る」機能は**要らない**（ユーザーが取り消した）。
- ノック専用のクリアマークを作る。
  - 種類は「クリア」「イージークリア」「未クリア」の3つ。
  - 画像はユーザーが用意する（まだ受け取っていない）。
